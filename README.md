# Politica de confidențialitate — Optiman Dashboard

Acest repo public există dintr-un singur motiv: Google Play cere ca politica de
confidențialitate a aplicației să fie accesibilă la un **URL public**.

- **Pagina publicată:** <https://claudiuanghel.github.io/optiman-privacy/>
- Aplicația: **Optiman Dashboard** (`com.optimanlogistic.app`)

Vechiul `privacy-policy.html` redirecționează spre rădăcină, ca linkurile date
înainte să rămână valide.

## Sursa de adevăr

Fișierul canonic este `play-store/privacy-policy.html` din repo-ul privat
`optiman-dashboard`. `index.html` de aici este copia lui publicată.

**Când modifici politica:** editează întâi fișierul din `optiman-dashboard`, apoi
copiază-l peste `index.html` aici și dă push. Așa nu ajung cele două variante să
spună lucruri diferite.

Repo-ul nu conține cod, chei sau date de business.
